# ADR 003: Baseline a conceptual study with explicit unknowns

Accepted. The first release supports one deterministic wildfire CubeSat scenario, with mass, power, data and RF preliminary sizing. Independent review explicitly challenges the inference from daily downlink capacity to 30-minute user delivery. Resolution records a verification task and residual risk; it does not claim flight feasibility.

Consequences: the workflow can finish as a human-approved conceptual baseline while uncertainty remains visible. Access propagation, lifetime, cost validation and payload sensitivity must be completed before a later feasibility gate. Every user sees this acknowledgement at baseline approval.
